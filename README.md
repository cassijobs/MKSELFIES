# MKSELFIES — protótipo

Projeto independente para reconhecer artes de produtos e criar fotografias com efeitos e frases.

## Pastas

- `app/`: experiência do usuário e câmera frontal.
- `studio/`: preparação local da experiência.

Nesta primeira versão, o reconhecimento da arte é simulado. A câmera, a composição da fotografia, o download e o compartilhamento já fazem parte do protótipo.
